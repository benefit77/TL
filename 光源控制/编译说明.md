# 编译说明

程序就在本目录（`libledim-gui`、`libledim-clidemo`），已经编好能直接跑。只有在**换了机器**（尤其换了 Linux 发行版/版本）
或**改了源码**时，才需要重新编译。

## 最省事：一条命令

在本文件夹里运行：

```bash
./编译.sh
```

它会：编译本工程 → 把编好的程序与库归位到根目录的 `libledim-gui`/`libledim-clidemo` 和 `libledim/`。

## 自己控制：三条命令

```bash
sudo apt install build-essential cmake      # 依赖，每台机器只装一次
sudo apt install qtbase5-dev                # 想要图形界面才需要
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

`build/` 里的布局和项目本身一样：程序在 `build/` 顶层，库在 `build/libledim/`。
重跑一次 `./编译.sh` 就会把它们拷回根目录；也可以自己 `cp build/libledim-gui .` 手动拷。

红帽系（CentOS/Rocky/Fedora）包名：`gcc make cmake qt5-qtbase-devel`。

## 跑起来

```bash
./libledim-clidemo list                      # 列出本机串口
./libledim-clidemo -p /dev/ttyUSB0 selftest  # 接上灯控板后的全通道自检
./libledim-gui -p /dev/ttyUSB0               # 打开图形界面并连接
```

接真实灯控板前先把账号加进 `dialout` 组（否则报 `os error 13`）：

```bash
sudo usermod -aG dialout $USER      # 然后注销重新登录
```

## 跑自测（可选，不需要硬件）

```bash
ctest --test-dir build --output-on-failure
```

用伪终端模拟一台灯控板，检查协议字节、命令行、界面接线。没装 python3 时这几个测试自动跳过；
其中"差分测试"需要一个旧版库作对照，本文件夹里没有，它会自动跳过并提示，不影响其他测试。

## 装到系统里（可选）

```bash
sudo cmake --install build                        # 装到 /usr/local
sudo cmake --install build --prefix /opt/ledim    # 或装到指定目录
```

装好后别的程序这样用：`gcc app.c $(pkg-config --cflags --libs ledim)`（程序里 `#include <libledim.h>`）。

## Windows 上编译

装了 Visual Studio 2022 + CMake 后：

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

产物是 `libledim.dll` + `libledim.lib`（在 `build\Release\libledim\`），C# 那边 `DllImport("libledim.dll")`
不用改。提醒：Windows 串口后端我这边没有编译验证过，第一次编完先用
`libledim-clidemo -p COM3 selftest` 试一下再上生产；Linux 侧是完整验证过的。

## 常见问题

**CMake 版本太老**（Ubuntu 18.04 自带 3.10，这里要求 ≥ 3.16）

```bash
sudo snap install cmake --classic          # 或改用 Kitware 官方 apt 源
```

**提示 "libledim-gui is off"**
没找到 Qt5，库和命令行照常编，不影响控制光源。要界面就装 `qtbase5-dev` 后重新编译。

**编好的二进制能不能直接拿到老系统用？**
不能。二进制对 glibc 只能往新处走：在 Ubuntu 24.04 上编的，要求 glibc ≥ 2.34，只能跑在
Ubuntu 22.04 及更新的系统上。所以在**目标机器上编**就对了——在哪编，就能在那台和更新的系统上跑。

**连不上灯控板**
依次检查：`./libledim-clidemo list` 看串口在不在 → `dialout` 权限 → 用
`./libledim-clidemo -v -p /dev/ttyUSB0 selftest` 打开详细日志，每一帧都会打出来。
