# 光源控制（LED 光源控制器）

**这一个文件夹就是全部。** 里面有编好的程序，也有源码；日常用不到源码。

| 你想干什么 | 怎么做 |
| --- | --- |
| 现在就控制灯 | 运行 `运行.sh`，按 `1` 打开图形界面 |
| 在别的机器上编译 | 把整个文件夹拷过去，运行 `编译.sh` |
| 只是看看有哪些文件 | 往下看第二段 |

## 文件夹里就这些

```
光源控制/                    ← 打开这个文件夹就是项目
├── 运行.sh                  ← 平时就用这一个（中文菜单：开界面 / 列串口 / 自检 / 权限帮助）
├── 编译.sh                  ← 在别的机器上重新编译
├── libledim-gui             ← 图形界面（可执行文件，就在根目录）
├── libledim-clidemo         ← 命令行程序（列串口、自检）
├── libledim/                ← 库：.so 在这里，头文件在 libledim/include/
├── 界面/ 命令行/ 测试/       ← 源码（想改程序才需要看）
├── CMakeLists.txt           ← 工程文件
└── 编译说明.md              ← 编译的详细步骤、常见问题
```

程序和库的关系：**程序在根目录，库在 `libledim/` 子文件夹里**（这一层结构跟你
`COM_and_CAN_TEST` 里 `libucan2/` 的摆法一样——程序运行时会自己去 `libledim/` 找库，
不用配环境变量）。所以整个文件夹拷走就行。

## 第一次用（三步）

1. 接好灯控板（USB 转串口插上就是 `/dev/ttyUSB0`）
2. 在本文件夹里运行 `./运行.sh`
3. 按 `1` 打开界面，点「搜索控制器」→ 选中串口 → 点「连接控制器」

连不上多半是权限问题（报 `os error 13`）：`sudo usermod -aG dialout $USER`，然后注销重登。
`运行.sh` 的 `4` 号菜单项就是讲这个的。

## 想改代码 / 在别的系统上用

见 `编译说明.md`。一句话：在本文件夹里跑 `./编译.sh`；
它等价于 `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j`。
源码按用途分在 `libledim/`（库）、`界面/`（图形界面）、`命令行/`（命令行程序）、`测试/` 里。
